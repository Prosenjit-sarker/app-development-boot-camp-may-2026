# Flutter App Scaffold

This folder contains a minimal Flutter project scaffold created in the workspace.

## Next steps

1. Install Flutter SDK:
   https://flutter.dev/docs/get-started/install
2. Open the `flutter_app` folder in VS Code.
3. Run `flutter pub get`.
4. Run the app with `flutter run`.

## Notes

- The app entry point is `lib/main.dart`.
- If you want the full platform folders, install Flutter and run `flutter create .` inside `flutter_app`.
